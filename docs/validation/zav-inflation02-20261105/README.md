# Dense inflation 0.2m curiosity trial

실제 ZAV + FAST-LIVO + OMMPC + PX4 SITL에서 사용자 요청대로 지도 팽창을 0.2m로 줄였다. 측정형상 hull, 계획 반경 0.43m, 계획 속도 1m/s, yaw rate 상한 1rad/s를 유지했다. 경로 유지 옵션은 껐다. 기존 비교 프로파일은 변경하지 않았다.

재현 시 기존 실행 절차의 플래너 명령:

```bash
./scripts/run_zav_forest_planner.sh dense 1 --inflation-radius 0.2
```

기존 회랑 바닥/천장 plane z=-0.1/3.3m가 유지되는 것도 실제 초기화 로그에서 확인했다.

초기 1.5m 높이 목표는 도달했다. 원본 편도 목표를 주자 A* 후보가 CIRI의 반경 조건에 걸려 출발점에서 호버링하며 재시도했다. 불가능한 seed 거절은 97회 기록됐다. 마지막 거리 0.412311m는 회랑 반경 0.43m보다 작았다. 같은 실패가 반복돼 약 126.8초에 시험을 중단하고 정상 착륙/disarm했다. 전체 임무 성공으로 집계하지 않는다.

[상세 결과](result.json), [독립 실제 body 검사](flight-report.json), 실제 사용 YAML과 원시 압축 로그를 보관한다. 이 결과는 현재 A*/CIRI 조합에서 팽창만 줄이면 조건 불일치가 발생한다는 뜻이며, 0.2m 팽창을 쓰는 모든 설계가 실패한다는 뜻은 아니다.

이전 시험의 입력 지연은 사용자 collision 확인 표시의 연산 부하였다는 설명을 별도 기록했다. 현재 시험은 입력 지연 보호를 끄지 않았다.
